# TOMC 自动请求接入说明（2026-10-22）

## 之前怎样省 token

TOMC 核心在本机用 CPU 从历史中选择证据、构造记录，再把较短的结果交给模型。只有模型请求实际采用该结果，输入才可能减少。MCP 插件可用、保存了笔记、小猫显示估算，都不能单独证明当前对话的输入已减少。

旧版的受控 API 风格测试确实验证过输入减少：一组长合成历史从 68,327 降到 15,596 个输入 token，五项答案均正确。但普通 Claude Code 的另一组短历史测试增加了工具调用，整轮费用由 $0.121 变成 $0.123。因此历史缩短、实际输入用量、账单差额必须分开。完整条件见 [旧验证记录](validation.md)。

## 新的请求路径

```text
Codex / Claude Code（原有界面、登录、模型）
  → 本机 TOMC 后台服务（仅 127.0.0.1）
  → 原有模型服务
  → 原样流式返回客户端
```

后台服务是 TOMC 的组件。用户不需要再开发一个客户端。MCP 继续负责显式取回上下文、笔记和跨会话操作；请求服务负责在发送前处理符合条件的旧历史，两者共享本地目录和会话开关。

- Codex 使用内置 OpenAI provider 的 `openai_base_url`。已有登录、模型、推理设置和审批规则保留。WebSocket 握手以 426 引导客户端使用 HTTP/SSE。
- Claude Code 使用 `ANTHROPIC_BASE_URL` 和官方会话/请求类别提示头。现有 claude.ai OAuth 保留，不把凭据复制进配置文件或数据库。
- 新会话默认允许 TOMC。会话身份来自实际请求，不以当前小猫窗口或最近打开的目录猜测。
- 只有足够长、可安全解释、处理后更短的旧历史才替换。当前轮、工具配对、宿主指令和未知协议内容受保护；短历史、宿主原生整理、辅助请求直接转发。
- Claude 的已签名推理需要固定前缀。关闭会话立即停止新编译；必要时继续使用此前已发送的前缀，直到宿主重置上下文。这不记作新的压缩或成长。

## 小猫和上下文目录

小猫从真实请求活动读取准备、转发、失败和用量状态。动画来自准备事件或处理完成事件；演示数据必须标为演示。处理失败不会计成成功减量。

目录保留逐会话开关、上下文正文、来源、复制接续提示词、导入和导出。导出是用户选择的上下文包，不自动把所有对话推送到 GitHub。导入其他电脑的包不会增加本机历史节省统计。

会话提示由实际会话事件触发。如果宿主只切换界面而没有发送请求或会话事件，TOMC 无法据此确认当前会话；下一次收到可靠身份后更新提示。

## 本机数据

| 数据 | 用途 |
|---|---|
| 会话 ID、来源宿主、启用开关 | 默认启用与单个会话关闭 |
| 已准备上下文、任务、来源 | 目录、接续、导出 |
| 请求 ID、阶段、原因代码、前后估算 | 状态、动画、避免重复计数 |
| 模型返回的输入与缓存 token | 实测用量；不是节省差额 |
| Claude 已编译前缀、原始前缀哈希与长度 | 重启后保持推理签名兼容；不另存原始请求 |

主数据仍使用 `~/.tomc/memory.sqlite3`。请求正文和认证头只用于内存中的转发，不写入访问日志。转发服务不开远程监听，不接受任意上游地址，不自动重复模型请求。

## 安装和恢复

独立、带时间戳的运行目录使用 `scripts/stage_request_gateway.py` 生成；依赖来自 `requirements-gateway.txt`。隐藏启动器可作为用户登录启动项，并在子进程退出后重新启动服务。

`scripts/install_request_gateway.py` 默认只预览。`--activate` 先检查本机服务健康，再备份并更新明确的客户端配置项和小猫模块。`--restore <receipt.json>` 只恢复安装后没有被再次编辑的文件；并发修改时拒绝覆盖。不会改登录、审批、模型配置或插件缓存。

客户端要重新启动才能加载新的用户配置。已经打开的客户端、远程执行环境、显式覆盖地址的项目，必须分别观察实际请求，不能仅凭配置推断已接通。

## 验收口径

自动接入必须由真实客户端请求证明，包含同会话续聊、实际改写、工具调用、事实保留、关闭会话、转发服务重启及 provider 用量。离线测试和界面预览不能替代这些检查。词法估算减少不直接换算成账单节省；缓存和附加调用会影响实际费用。

本次真实验收和安装结果见 [交付记录](TOMC_016_delivery_20261022_zh.md)。实测输入减少与缓存命中变化同时保留，未将它们表述为账单节省。
