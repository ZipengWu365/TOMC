# TOMC · 省 token 小猫

2026-10-18 最新用户方向：沿用认可的毛绒猫头，眼睛稍大；四个进化阶段越来越威风，究极形态加皇冠和头两侧的翅膀，始终没有身体、脖子、四肢和口袋。名称统一为 TOMC，说明用“省 token 小猫”。

四个阶段始终名为 TOMC，仅外观进化，多计数器状态也不改名。内置 imagegen 基于认可的猫头编辑四种外观：第一阶浅色稀疏细绒，第二阶适中短绒、紧凑脸颊，第三阶浓密厚绒、饱满脸颊与棕色眉毛，第四阶黄毛、金冠与象牙色小翅膀。前三阶没有黄色额顶毛簇或金色额纹。当前每阶段使用一张透明双帧表情图，左帧待机没精打采、委屈放空，右帧处理上下文时开心。主色来自燕麦色毛绒、棕色耳尖与深棕眼睛，金色用于究极形态装饰；普通纸片包含黄色 #F2D77B。无现成品牌角色或标识。

正常原生挂件为 72×80 逻辑像素；处理上下文时画布临时扩为 132×147，动画结束绘制区域立即恢复 72×80。132 px 是活动画布宽度，不是每一帧猫头轮廓的宽度：第二阶猫头在该区域内缩小并移至左下，为右上方纸张留出位置；其他阶段平滑放大并缩回。四阶段动画时长分别为 2.4 / 3.4 / 2.8 / 3.2 秒。窗口靠屏幕边缘时保持在工作区内。短暂结果气泡显示时整体窗口为 257×110，气泡隐藏后回到 72×80；主动点击可展开独立统计面板。

第一、三、四阶分别让纸片飘落、左右汇流、旋转吸入嘴里。第二阶改为三次快速顶撞：在归一化进度 0.28 / 0.38 / 0.48 撞击大张散纸，将纸张逐次压紧、对齐为带绿色标题条的小卡片，然后显示勾号并向右上方交付；第二阶不吞纸。撞击只有局部接触短线，不震动桌面。四种动画期间均使用自带张嘴笑容的右帧，不额外绘制嘴巴；翅膀不作为独立骨骼动画。动画由准备结果事件触发，只示意上下文处理，不是实际压缩进度。没有常驻粒子、闪光或背景。

延续既有统计：0 / 10,000 / 100,000 / 1,000,000 门槛，凝实度 35% / 58% / 82% / 100% 连续插值，最高净累计保留解锁。文字不随角色淡化。界面仍为原生 Qt，默认字体 Microsoft YaHei UI，主要数字用 Segoe UI。数字为上下文 token 估算，不是 API 账单节省。

## 点击展开的资料面板

点击猫头打开以百分比为主的暖奶油色面板（底色 #FFFCF7、细边框 #E8E2D8、圆角 14 px），宽度固定 240 px；标准收起详情状态离屏约高 186 px，内容换行或展开详情时高度随内容变化。顶部是 26×29 px 的委屈放空头像、固定名称 TOMC 和等级。22 px 高的“今天 / 近七天 / 累计”按钮下面只展示上下文减少或增加比例、最近一次比例，以及独立的 Codex 剩余额度。原始 token 数、准备次数、各计数器数据、凝实度与成长进度放入“详情”。单次结果气泡也显示百分比。打开面板不改变待机猫头的 72×80 px 大小，也不触发笑脸或处理动画。

“上下文估算，不等于额度节省”始终可见；测试模式的“演示”标记也始终可见。上下文比例按同一计数器的（所选时段原文总量−整理后总量）/原文总量计算，不平均单次百分比。负减少显示“上下文增加”及正数幅度；原文总量为零时显示“—”，多计数器主值显示“分口径”，详情分别列出，不合为总数。读取失败时显示重试状态，不把故障显示为零。面板顶部 × 只收起统计；底部或右键菜单的“退出 TOMC”退出挂件，同时停止它自行启动的额度读取辅助进程，保留其他 Codex/MCP 服务。

额度一行通过已登录的 Codex CLI 启动官方 `app-server`，异步调用只读 `account/rateLimits/read`，每 60 秒刷新并接收额度更新通知；不启动推理、登录、重置额度或购买操作。读取失败会清除过期值并显示“暂不可读”，之后重连。解析优先使用多额度桶数据，缺失或 null 不当作零，各额度桶及周期分别保留，剩余百分比限定在 0–100；主行优先显示 Codex 桶的一个周期，其余周期在详情列出，不求和。官方接口见 [Rate limits](https://learn.chatgpt.com/docs/app-server#6-rate-limits-chatgpt)。真实账户余额与上下文压缩比例分开；模型、上下文、推理、工具、检索与缓存均会影响额度消耗，不能按压缩比例换算额度节省，见 [官方用量说明](https://learn.chatgpt.com/docs/pricing)。
