# TOMC Memory 0.3.1 更新说明

[English](release_notes_0.3.1.md) | **简体中文** · 2026-10-31 · 发布标签 `v0.3.1-preview.1`

0.3.1 主要改界面：小猫平时就能看出省了多少，金额都写成估算，演示页打开就有结果，另外多了一张能发出去的"本周战报"。压缩规则和 MCP 工具跟 0.3.0 一样，论文用的编译核心没有改。0.3.0 改了什么见 [0.3.0 更新说明](release_notes_0.3.0_zh.md)。

## 本周战报

- 小猫右键菜单、看板和分析页里都有 **本周战报**，会把最近 7 天画成一张图：少发了多少 token、7 天柱状图，再加几格小数据。可以复制，也可以存成 PNG，有竖版（1080×1350）和横版（1200×630）。终端里用 `tomc share-card`。
- 图在本机生成，不上传。卡上没有对话名、文件夹、提示词或 ID。
- 每个数字都标"≈"或"估算"，页脚固定写"上下文估算，不等于账单或额度节省"，关不掉。不知道标价就不显示金额；可用记录少于 5 次只写"样本太少"；这周没省到就照实写。演示数据会铺满水印。
- 说明：[本周战报](share_card_zh.md)。

## 桌面小猫

- 猫头下面常驻"今日 −82K"这样的小标签，平时不再半透明发灰。今天没省到时不显示，不会写 0。
- **小猫跟着省下的量长大。** 四个样子改成看累计少发了多少 token（估算）：大约 10 万、100 万、1000 万各长一次。长到的样子不会退回去，就算后面某次上下文变长了也一样；长大时会弹一个气泡。以前是看单次上下文有多长，要过 100 万才到最高阶段，大多数人一直看不到它变。现在单次长度只决定那次动画里飞多少纸片，分析页里那张图也改叫"长度档"，不再叫阶段。
- 整理完弹出的气泡里，"本次节省"是唯一的大数字，原上下文放在小字里；省到了猫会笑。
- 所有金额统一写成"按标价估算 ≈ $x"，鼠标停上去会提示"不是账单；有缓存或订阅时实际更少"。看板和"模型与估价"页现在用同一个算法，不会一边写 $1.68、一边写"不估算"。
- 界面上不再出现 `short_history` 这类内部代码，都换成了一句大白话；不认识的代码显示"已原样发送"。看板底部三行技术状态合成了一个圆点加一句话。
- 改掉了一些行话，比如"宿主"改成"助手"，连接状态写"已接入 / 未接入"。
- 右键菜单里"退出"放在最后。没有标题的对话显示"未命名对话"，不显示 ID；新会话提醒只弹一次。读不到数据时，旧的模型金额和柱状图会一起清掉。
- macOS 上的主色从系统蓝换成品牌墨绿。

## 演示页

- 系统是深色模式时，品牌名和标签页不会再看不见。
- 默认中文，右上角可切 English，页头有小猫和"改过的事，只记最新的"。
- 打开就现场跑一遍 `tomc try` 用的同一份 120 天项目聊天（预算 200），第一行是大数字"少发 6,015 token（−96%）· 估算"。这里算的是整段请求（说明 + 问题 + 记忆），比 `tomc try` 只算历史的 −97% 更严。
- 结果下面左右对照：左边是原文里带上的行，右边是交给模型的内容，每行都标出原文行号。
- 减少一律写"−"，变多就直接写"上下文增加了"。"30 秒导览"换成了能看出压缩效果的例子；原来 31 → 36 的例子挪到"局限：很短的聊天"里。
- 页脚版本号跟着软件版本走，手机宽度不会再横向滚动。

## AI 失忆现场

- 新增讨论区表单和 issue 表单：讲讲 AI 在长对话里把改过的事记错的经过。提交前必须勾选"我已删掉私人内容"。
- 好的故事会改写成合成例子，放进 `examples/amnesia/` 并加回归测试，提供者署名。每条都标"用户自述，未复现"或"已复现（附命令）"；这些故事是自己挑出来的，不能拿来算"多少 AI 会失忆"。

## 没变的

- 压缩、最新值规则、MCP 的十二个工具、默认不保存，都和 0.3.0 一样。
- 0.3.0 的数字（旧值体检、`tomc try`）都还成立，[证据页](evidence_zh.md)不用改。

## 怎么升级

- **插件。** Claude Code：用 `/plugin` 更新，新开会话。Codex：下载 0.3.1 的 ZIP，重新运行安装器。Claude Desktop：安装 0.3.1 的 `.mcpb`。
- **桌面小猫。** 重启一次小猫就能看到新界面。
