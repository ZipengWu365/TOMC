# 首次体验私测：任务与记录

状态：尚未邀请、尚无结果。由作者选择 5 位目标用户并取得参与同意。测试只使用合成输入，不保存真实对话；不需要录屏，除非参与者另行同意。不要事先讲解 TOMC 的方法。

## 主持人任务卡

1. 打开默认“直接使用”页，看 10 秒，用自己的话解释它如何帮助大模型使用历史。用合成研讨会笔记生成上下文并复制。
2. 进入 30-second tour，解释为什么 `drink` 与 `backup_drink` 不同，并找到支持这个结果的两条来源。
3. 进入 Workbench，选择快照样例，将最后的 drink 改为 `water`，编译并核对当前值与副本。
4. 提出“为什么改变”的问题，找到适用范围说明，判断单独状态能否回答。
5. 按 README 在自己的环境运行 `examples/snapshot.py`；允许安装依赖的网络时间单独记录。

只在参与者卡住超过 60 秒后提供帮助，并记录帮助内容。完成时问：你会把它用在什么任务上？哪个地方最让你犹豫？不要问“你喜不喜欢我们的设计”来替代任务完成数据。
